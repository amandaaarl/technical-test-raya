# Simple FizzBuzz - JS

Program kecil untuk menampilkan angka 1 sampe 100 pake Node.js dengan aturan kelipatan 3 jadi Fizz, 5 jadi Buzz, dan kelipatan keduanya jadi FizzBuzz.

## Cara Pakai
1. Pastikan sudah install Node.js.
2. Buka terminal di folder ini.
3. Jalankan perintah:
   ```bash
   node fizzbuzz.js
