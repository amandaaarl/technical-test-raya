# Simple Todo App - React

Aplikasi web sederhana untukk mencatat daftar kegiatan sehari hari (CRUD: Create, Read, Update, Delete) yang dibuat memakai React (Vite) dan Bootstrap.

## Cara Pakai
1. Pastikan sudah install Node.js.
2. Buka terminal di folder ini.
3. Install modul yang dibutuhkan (kalau belum install):

   npm install
